Welcome. This project is a **<span data-variable="productType">{{variable.productType}}</span>**
project, which means one thing above all others:

> **Your documentation lives in a Git repository, and the repository is the source of truth.**

Everything else follows from that sentence. The pages you write are Markdown files. Their order is a
file you can read. A change becomes visible to readers when it reaches the branch that publishes.

## If you have used Document360 before

You may have used **<span data-variable="siblingType">{{variable.siblingType}}</span>**, the
editor-first product type, where content lives in Document360 and the portal is where you work. Both
product types exist, both are supported, and they are not stages of each other.

> [!IMPORTANT]
> **The editor is the same; the source of truth is not**
>
> You write in <span data-variable="editorName">{{variable.editorName}}</span> in both product types.
> What changes is where the result is stored and how it reaches readers.

## What you need

- [ ] Access to this project in Document360.
- [ ] Access to the Git repository behind it, if you want to work outside the portal.
- [ ] Nothing else. You can do everything in this section from the portal alone.

> [!TIP]
> **You do not have to use Git to work here**
>
> Writers who prefer the portal never have to touch a command line. The repository is how the content
> is *stored*, not a tool you are obliged to use. Those who do want it get the whole of Git.
